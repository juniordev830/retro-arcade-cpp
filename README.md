# Retro Arcade C++ Engine

A high-performance C++ 2D Game Engine core featuring Vector math, Entity Component System (ECS) architecture, and fixed step game loops.

## 🕹️ Engine Core Features

- **Vector2 Math Library**: Dot products, normalization, distance checks.
- **Entity Component Architecture**: Component management for game entities.
- **Fixed Delta Game Loop**: Deterministic frame updates.

## 🚀 How to Build & Run

```bash
g++ -std=c++17 main.cpp -o arcade_engine
./arcade_engine
```
